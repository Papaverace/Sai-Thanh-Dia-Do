# Sài Thành Địa Đồ

Dấu chân đỏ thuở cách mạng. Website dự án môn Lịch sử **"Khắc dấu rạng đông"** của lớp 11A2, Trường THPT Lê Quý Đôn.

Trang web giới thiệu 4 địa điểm cách mạng ở TP. Hồ Chí Minh: Dinh Khâm Sai, Ngã Ba Giồng, Cà phê Đỗ Phủ – Cơm tấm Đại Hàn và Địa đạo Phú Thọ Hòa.

**Xem web:** https://papaverace.github.io/Sai-Thanh-Dia-Do/

## Nhóm thực hiện
- Trân, Minh: lập trình
- Nam, Khang: ý tưởng
- Di: thiết kế giao diện
- Đức, Mon: tư liệu, hình ảnh

## Cấu trúc
- `index.html`: toàn bộ trang; dữ liệu nằm trong mảng `SITES`, ảnh khai báo trong `IMG`
- `img/`: ảnh tư liệu
- `hero.jpg`, `logo.png`: banner và logo
